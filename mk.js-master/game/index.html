Instrucciones

  • Usa las siguientes teclas para controlar a tu luchador:
  • ↑ - Saltar
  • ↓ - Agacharse
  • ← - Moverse a la izquierda
  • → - Moverse a la derecha
  • A - Puñetazo hacia arriba
  • S - Puñetazo hacia medio
  • D - Patada
  • Espacio - Reiniciar juego
  • Para jugar en red, ambos jugadores deben estar en la misma red WiFi o LAN.
  • El primer jugador debe responder yes a "Are you going to be host?" y crear el juego con un nombre.
  • El segundo jugador debe responder no y escribir exactamente el mismo nombre de juego para unirse.
  • Si juegas desde otro dispositivo, accede a http://IP_DEL_HOST:3000 desde el navegador.
